# P0 ADR/SLO Decision Package

Status: accepted by user instruction on 2026-08-13.

Scope:

- ADR-0001 through ADR-0009 are accepted for P1 entry.
- P0-06 preview SLOs, release gates, read-back gates and parity tolerances are
  accepted for P1 entry.
- Known-defect approval for CBWNG and FRWAJ applies only to immutable legacy
  baseline evidence. It does not weaken IDS, release gates, semantic parity
  gates or future PMD release requirements.

Decisions:

- Proceeding past Gate P0 is allowed only if the gate review records known
  defects as accepted legacy-baseline deviations and keeps release publication
  blocked for failed gates.
- API, frontend, editor and RAG remain prohibited until Gate P3 / PMD Stable.
- P1 may start only after the repeated Gate P0 review records all P0 criteria as
  passed or accepted with explicit non-release limitations.

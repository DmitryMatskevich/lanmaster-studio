# Librarian Guide

## Purpose

Use Studio to maintain catalog records, source evidence, model revisions and
release manifests for LANMASTER model families.

## Required Workflow

1. Store every supplier drawing, PDF, SVG, DXF, STEP, IFC and GLB source with
   provenance and SHA-256 hash.
2. Track missing dimensions, conflicting article names and source gaps as
   explicit questions.
3. Verify generated model, source and view folders before sharing repository
   links.
4. Ensure component tables include all numbered construction details from the
   source drawing; split pages when tables do not fit.
5. Keep email replies detailed about what was changed, what remains uncertain
   and which repository path contains the result.

## Release Evidence

Release evidence must include source hashes, generated artifact hashes, view
renders, model files and acceptance status.
